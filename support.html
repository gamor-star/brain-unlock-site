BrainUnlock Support

Need help setting up BrainUnlock, choosing protected apps, using Screen Time permissions, or understanding how app access works? We are here to help.

Contact

Email: support@brainunlock.app

Please include your iPhone model, iOS version, and a short description of what happened. If the issue involves protected apps, include whether you selected individual apps or an app category in Apple's Screen Time picker.

Setup help

  • Create an access code during onboarding so the app settings stay protected.
  • Allow Apple's Screen Time / FamilyControls permission when prompted.
  • Select the apps or categories you want BrainUnlock to protect.
  • Choose your challenge rules and unlock duration in Controls.
  • Use Lock Down from the app when you want protected apps shielded again.

Screen Time notes

BrainUnlock relies on Apple's Screen Time and FamilyControls APIs. App shielding works on real iPhones with Screen Time authorization. Some behavior, including how quickly a shield appears over an app that is already open, may depend on iOS.

  • If a protected app does not shield, reopen BrainUnlock and check Screen Time status in Controls.
  • If access does not open, confirm at least one protected app or category is selected.
  • If a protected app remains blocked, check whether separate Apple Screen Time restrictions are enabled outside BrainUnlock.
  • Screen Time shielding is not expected to work in the iOS Simulator.

Access code help

BrainUnlock stores the access code securely on the device. The access code may survive app deletion and reinstall because iOS secure storage can be Keychain-backed. If you need help with access-code recovery or resetting the app, contact support.

Privacy and data

BrainUnlock is local-first in the current version. There are no accounts, ads, third-party analytics SDKs, or backend servers. Challenge summaries, settings, access-code security data, and Screen Time selection tokens are stored locally to operate the app.

  • Read the Privacy Policy.
  • BrainUnlock does not sell or share personal data.
  • BrainUnlock does not use cross-app tracking or advertising identifiers.
