Common setup notes

  • BrainUnlock requires Apple Screen Time / FamilyControls permission for app shielding.
  • Protected apps must be selected through Apple's Screen Time picker.
  • Screen Time shielding only works on a real iPhone, not the iOS Simulator.
  • If a protected app remains blocked, check whether Apple Screen Time restrictions are also enabled outside BrainUnlock.
  • The parent access PIN may survive reinstall on the same device because iOS SecureStore is Keychain-backed.
