Setup help

  • Create an access code during onboarding so app settings stay protected.
  • Allow Apple's Screen Time / FamilyControls permission when prompted.
  • Select the apps or categories you want Brain Unlock to protect.
  • Choose challenge rules and unlock timing in Controls.
  • Use Lock Down when you want protected apps shielded again.

Screen Time notes

Brain Unlock relies on Apple's Screen Time and FamilyControls APIs. App shielding works on real iPhones with Screen Time authorization. Some behavior, including how quickly a shield appears over an app that is already open, can depend on iOS.

  • If a protected app does not shield, reopen Brain Unlock and check Screen Time status in Controls.
  • If access does not open, confirm at least one protected app or category is selected.
  • If a protected app remains blocked, check whether separate Apple Screen Time restrictions are enabled outside Brain Unlock.
  • Screen Time shielding is not expected to work in the iOS Simulator.

Access code help

Brain Unlock stores the access code securely on the device. The access code may survive app deletion and reinstall because iOS secure storage can be Keychain-backed. If you need help with access-code recovery or resetting the app, contact support.

Subscriptions

Brain Unlock Pro subscriptions are purchased through Apple's in-app purchase system. If a subscription is active but the app does not unlock paid access, open the paywall and use Restore Purchases. If that does not work, contact support.

Privacy and data

Brain Unlock is local-first in the current version. There are no accounts, ads, backend behavior analytics, or Brain Unlock account servers. RevenueCat is used for subscription entitlement checks. Challenge summaries, settings, access-code security data, and Screen Time selection tokens are stored locally to operate the app.

  • Read the Privacy Policy.
  • Brain Unlock does not sell or share personal data.
  • Brain Unlock does not use cross-app tracking or advertising identifiers.
