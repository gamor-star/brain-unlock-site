How it works

One clean loop: protect, solve, unlock, relock.

The app is built around a simple, predictable flow so setup feels understandable and daily use feels intentional instead of chaotic.

01

Choose protected apps

Select individual apps or categories with Apple's Screen Time picker.

02

Complete a challenge

Use short thinking checks, memory, pattern, and path puzzles.

03

Access opens

Protected apps become available for the window configured in Controls.

04

Protection returns

When the session ends, Brain Unlock restores app shields.

Privacy and trust

Built for iPhone, built to stay quiet.

Brain Unlock is local-first. There are no accounts, ads, backend behavior tracking, or data broker integrations in the current app.

  • No advertising or cross-app tracking
  • No child name, location, contacts, photos, or browsing history collected
  • Settings and challenge summaries stay on device
  • Apple Screen Time tokens are stored locally to operate shielding
